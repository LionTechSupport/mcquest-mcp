## 4. Non-Negotiable Invariants (carried forward from V0.5)

The following MUST remain true through v0.6:

- normal presentation budget ≤ 4000 characters
- absolute response ceiling ≤ 16000 characters
- per-line clip ≤ 200 characters
- explicit pagination only (no automatic page 2)
- deterministic ordering `(relative_path ASC, line ASC)` where applicable
- root confinement preserved
- ignored-directory / ignored-extension policy preserved
- symlink safety preserved
- read-only behavior preserved
- no writes to the target repository
- text output only
- no new security surface
- no `_meta`, no file-backed response artifacts, no `format=json`

---

## 5. Phase 0 Scope Discipline

Phase 0 must NOT add, and v0.6 should not authorize without explicit user
approval:

- semantic/vector search, embeddings, AI summarization
- repository indexing
- execution tools
- generated-artifact access
- broad language support
- new security surfaces
- unrelated refactoring

Fix only the smallest set of changes that materially improves agent evidence
efficiency/reliability (recommendations in `05-V0.6-DECISIONS.md`).
