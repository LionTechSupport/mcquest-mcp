## 2026-09-17 — V0.7 Stage 3 implemented (mcquest_locale_inspect JSON locale inspection)

Status: **IMPLEMENTED — DEC-012 scope (D-1..D-7 approved); no commit/push**

- New read-only tool `mcquest_locale_inspect(path=".", reference="",
  file_pattern="*.json", max_results=50, offset=0)`: JSON-only locale
  inspection — STRUCTURE (root shape + per-node effective key/array
  counts), DUP (exact duplicate keys at effective object nodes over the
  full syntactic pair list), COLLISION (casefold groups, e.g.
  `Straße`/`strasse`), and — only with an explicit reference file —
  MISSING/EXTRA key-path diffs. `reference=""` means
  structure/collision/duplicate inspection only; no default locale is
  ever inferred.
- D-1 duplicate-preserving parse: `json.loads(...,
  object_pairs_hook=_Pairs)`; effective structure follows the last
  occurrence; shadowed earlier subtrees are never traversed or reported
  (the shadowing event itself IS a DUP); arrays positional (`"0"` key vs
  `[0]` index distinct everywhere); D-5 path display (JSON-quoted keys,
  `[i]` indices attaching directly, `<root>`; renderer-only 200-char
  line clip).
- D-2/D-4/D-6/D-7: raw-text depth pre-check; approved limits kept
  exactly (2000/500/200/100000/8000000/64000000/3000/5000/2000000/
  1000000); `MAX_PARSE_NODES_PER_FILE` retained as a documented
  invariant guard, NOT an RSS/parse-allocation ceiling; identity bounds
  charged atomically at commit (no partial identity); exact
  FINDINGS_OMITTED / FINDINGS_UNKNOWN / files_not_examined accounting;
  conservative enumeration completeness (files_not_examined_unknown +
  ENUM_LIMIT/ENUM_REASON); deterministic byte-order files and typed-path
  row order (STRUCTURE0 COLLISION1 MISSING2 EXTRA3 DUP4 ERROR5); per-file
  cap (3000) before global cap (5000); counting mode after global
  exhaustion; error rows consume cap slots with ERROR_ROWS_OMITTED
  disclosure; collection_complete=false whenever comparisons are
  disabled or the scan is incomplete.
- Files: `src/mcquest_mcp/tools/locales.py` (new),
  `src/mcquest_mcp/tools/__init__.py`, `src/mcquest_mcp/server.py`
  (registration, 19 tools; instructions), `src/mcquest_mcp/formatting.py`
  (backward-compatible `search_block(collection_complete=True)` param),
  `tests/test_locale_inspect.py` (new, 39 tests),
