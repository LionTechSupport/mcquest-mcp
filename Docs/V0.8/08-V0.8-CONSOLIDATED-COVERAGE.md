## 4. Deferred Item: `mcquest_audit_summary` (DEC-011)

The predecessor package proposed `mcquest_audit_summary` as an **optional** fifth tool (aggregating the four core audits into a bounded review summary: top findings, affected files, risk summary, recommended review order).

**Disposition: DEFERRED (DEC-011).** On 2026-09-20 the user confirmed that the deferral stands and that the tool is **not** added as a fifth V0.8 tool.

Rationale:

- The predecessor package itself marked the tool as *optional*.
- The approved V0.8 specification commits to a four-tool scope.
- Adding it would materially expand the accepted specification (registered tool count 20 → 25 instead of 20 → 24, a new contract section, and test-plan and server-instruction changes), which per DEC-021 requires a new product decision.

Reconsideration would require a separate, explicit product decision. Registered tool count for V0.8 remains **20 → 24** (DEC-020).
