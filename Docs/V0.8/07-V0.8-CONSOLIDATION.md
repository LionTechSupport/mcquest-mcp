## 5. Design Choices — Final Disposition (2026-09-20 fix pass, D1–D7)

The previously provisional defaults were resolved by user decisions D1–D7 on 2026-09-20 (docs-only; recorded in `05-V0.8-DECISIONS.md`):

1. Four new standalone, narrow, read-only audit tools (shared internal reuse; DEC-019). — DECIDED
2. Lexical-only UI-candidate classification; parser-grade and semantic UI classification remain reserved (DEC-015). — DECIDED
3. Evidence-first output; labeled summary/severity views; review-checklist recommendations only; all labels are heuristics (DEC-017). — DECIDED
4. `mcquest_find_ui_text` / `mcquest_ui_contract_audit`: full-scan two-pass; `mcquest_doc_gap_audit` / `mcquest_feature_impact_audit`: capped-scan with `collection_complete=false` + NOTE (DEC-016). — DECIDED
5. Single-scan feature-impact audit; comparison-mode deferred. — DECIDED
6. `mcquest_audit_summary` deferred (DEC-011; confirmed 2026-09-20) — not added as a fifth tool (`08-V0.8-CONSOLIDATED-COVERAGE.md` §4); client wrappers deferred (DEC-012). — DECIDED
7. Budget values binding (≤4000 / ≤16000 / ≤200; explicit pagination only; deterministic ordering; root confinement; P004/P005 semantics) (DEC-013). — DECIDED
8. Severity `info`/`warning`/`critical`; confidence `low`/`medium`/`high`, heuristic-labeled, with fixture mapping rules required before implementation (DEC-009/DEC-017). — DECIDED
9. All tools read-only; no document-correction or write authority (DEC-014). — DECIDED
10. The undefined “accounting model” term is removed. — DECIDED
11. Registered tool count 20 → 24; server-instruction updates (DEC-020). — DECIDED
12. Missing-required-prop findings: `critical` requires a complete, fully evaluable all-sites claim; partial omission is `warning`; incomplete/unevaluable coverage is never `critical` (DEC-022). — DECIDED
13. `stale_prop` is `warning` only against a fully available definition; otherwise `unverifiable` (DEC-023). — DECIDED
14. Risk is per finding with the scale deferred (no `risk` values); confidence is evidence-sufficiency based (DEC-025). — DECIDED
15. Text extraction boundaries (comments/JSX out of scope; `include_brand` deferred; fenced doc tokens), path/error behavior, budget-cut/continuation behavior, and canonical rule ownership (DEC-026…DEC-029). — DECIDED
16. Consistency row type (DEC-024), `feature_scope` (DEC-030), and the import-allowlist artifact (DEC-030) remain UNRESOLVED blockers for their specific features/test areas. — OPEN
17. `mismatched_usage`/`signature_drift` severity recorded as `warning` with fixture phenotypes; `include_admin` removed/deferred while `admin-only` is non-emittable; find_ui_text completeness canonicalized in contract §2.1 (DEC-031). — DECIDED
18. `mcquest_find_ui_text` classification rules and `classify` semantics recorded (DEC-032): `decorative` (no ASCII letter) and `unknown` (letter-bearing; reason names the missing brand-token and admin-marker lists) are emittable; `localizable`/`brand`/`admin-only` are NOT EMITTABLE and `localizable` is never inferred by elimination; `classify` defaults to `true`; implementation of `mcquest_find_ui_text` only was authorized and performed (uncommitted; tests pending). — DECIDED
19. `mcquest_doc_gap_audit` evidence and bounded-scan rules recorded (DEC-033): `stale_reference` carriers are inline backtick-span content and path-like tokens with a recognized extension (the identifier form is a tokenizer within carriers, never a standalone carrier over prose); `conflicting_reference` is NOT EMITTABLE until a lexical contradiction evidence rule and its severity/confidence mapping are recorded; bounded-scan limits `MAX_ENUMERATE_FILES = 2000` / `MAX_FILES_ANALYZED = 500` with `total` counting findings within the bounded scan only; docs-only, authorizing no implementation. — DECIDED
20. `mcquest_feature_impact_audit` boolean defaults and bounded-scan limits recorded (DEC-034/DEC-035): `include_docs`/`include_locales` default to `true` (no new output fields/enums/classifications); bounded-scan limits `MAX_ENUMERATE_FILES = 2000` / `MAX_FILES_ANALYZED = 500` under the DEC-016/DEC-028 capped-scan model with `total` counting findings within the bounded scan only; docs-only, authorizing no implementation. — DECIDED

The consolidated specification was **approved by the user on 2026-09-20** (DEC-021); these decisions do not by themselves authorize implementation. Phase 1 coverage verification and Phase 2 predecessor-package removal are complete; implementation begins only after explicit Phase 3 authorization.
