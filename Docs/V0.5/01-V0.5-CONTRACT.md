## Binding Clarifications

These decisions supersede any ambiguous wording elsewhere in this document.

1. NORMAL_PRESENTATION_BUDGET = 4000 characters.
2. ABSOLUTE_RESPONSE_CEILING = 16000 characters.
3. Context amplification MUST NEVER cause the normal presentation budget
   to exceed 4000 characters.
4. `find_evidence.total` is the authoritative merged-stream total,
   or count-so-far when collection is incomplete.
5. `find_evidence.total` MUST NEVER be calculated using `min(code, docs)`.
6. Pagination is explicit only.
7. No automatic page 2.
8. Deterministic ordering is `(relative_path ASC, line ASC)` where applicable.
9. Per-line output MUST be clipped to 200 characters.
10. Existing root confinement MUST remain intact.
11. All v0.5 tools remain read-only.
12. Output remains text-only.
13. No `_meta`.
14. No file-backed response artifacts.
15. No `format=json`.
16. No `max_chars` parameter in v0.5.
